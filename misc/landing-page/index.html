Instant Playback for Data-Edited Videos

Exploring multimodal datasets means editing videos with data: "Show me every time X happens", "Draw a box over each Y", "Overlay Z telemetry on this video". Scripts, usually Python and OpenCV, are the only tool expressive enough for these tasks, but they take minutes or hours to render. Just change import cv2 to import vidformer.cv2 as cv2 and play the result instantly, no matter how long your video is.

How Vidformer Works

Vidformer uses a declarative data model to combine three techniques:


1) Declarative Lifting

An API shim uses symbolic computation to losslessly lift imperative code into a declarative specification. The code actually runs, but with mock frames.

2) Optimized Rendering

The full edit specification is known in advance, so the rendering engine transparently optimizes and parallelizes rendering. It handles worst-case frame access patterns, not just typical ones, and uses GPUs when available.

3) Video on Demand

Result videos are served as a standard VOD stream, with each segment rendered just in time. Playback latency is independent of video length, and the stream grows as the script runs.

"Show me ..." Conversational Video Exploration

When operated by an LLM agent, Vidformer lets users explore multimodal datasets through conversational video queries in real time. Ask for what you want to see in natural language, and newly edited video results start playing in seconds.
